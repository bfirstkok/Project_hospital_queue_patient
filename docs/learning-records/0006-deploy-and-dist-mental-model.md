# ผู้เรียนเข้าใจสายพานการ Build และบทบาทของโฟลเดอร์ dist ในการ Deploy

บันทึกความเข้าใจเรื่องวงจรการผลิตซอฟต์แวร์ด้วย Next.js Static Export: ตั้งแต่การล้างไฟล์เก่า (`clean-build`), การฉีดคอนฟิก (`write-runtime-config`), การคอมไพล์ (`next build`), จนถึงการจัดระเบียบโครงสร้างพร้อมสคริปต์ redirect (`publish-export`) เข้าสู่โฟลเดอร์ `dist/` และเข้าใจว่าโฟลเดอร์นี้คือผลผลิตสำเร็จรูปที่พร้อมนำไป deploy บน Static Web Server ใดๆ โดยไม่ต้องพึ่งพา Node.js อีกต่อไป
