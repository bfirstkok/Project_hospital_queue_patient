# ผู้เรียนเข้าใจความแตกต่างระหว่างเครื่องมือสร้าง (scripts/) และผลผลิตที่ส่งมอบสู่สาธารณะ (public/)

บันทึกความเข้าใจเรื่องการแบ่งบทบาทในโปรเจกต์ Next.js: `scripts/write-runtime-config.mjs` ทำหน้าที่เป็นผู้ดำเนินการ (Generator/Tooling) ในขณะที่ `public/runtime-config.js` เป็นผลผลิตแบบ Static Asset (Artifact) ที่เปิดให้เว็บบราวเซอร์ของคนไข้เข้าถึงได้ผ่านโครงสร้างพื้นที่สาธารณะของ Next.js
