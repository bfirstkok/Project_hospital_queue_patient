# ปรับความเข้าใจ: .env ไม่ใช่ตัวสำรอง (Backup) แต่เป็นแม่พิมพ์ต้นทาง (Source of Truth) และ 127.0.0.1:8000 คือที่อยู่ของ mock_backend.py

แก้ไขความเข้าใจผิดเรื่อง .env ว่าไม่ใช่ตัวสำรองของ runtime-config แต่เป็น "ต้นฉบับการตั้งค่า (Source of Truth)" ในสภาพแวดล้อมของนักพัฒนา ที่ถูกสคริปต์นำไปสร้างเป็น runtime-config.js อีกทอดหนึ่ง และชี้แจงว่า URL `http://127.0.0.1:8000` ชี้ไปยัง `mock_backend.py` ที่รันอยู่บนเครื่องตนเอง เพื่อใช้ทดสอบการทำงานของ Next.js และชุดทดสอบ Playwright E2E แบบออฟไลน์โดยไม่ต้องพึ่งพาเซิร์ฟเวอร์จริง
