Lesson 0004 • Project Structure

scripts/ กับ public/
ทำความเข้าใจความต่างระหว่าง "เครื่องพิมพ์ป้าย" กับ "ตัวแผ่นป้ายประกาศ"

บทก่อนหน้า: 0003: .env vs Runtime Config

1. ภาพเปรียบเทียบที่เข้าใจง่ายที่สุด 🏥

ความสัมพันธ์ระหว่าง scripts/ กับ public/:
  • scripts/write-runtime-config.mjs คือ "พนักงานเขียนป้ายประกาศ" (ทำงานอยู่ในห้องทำงานหลังโรงพยาบาล คนไข้มองไม่เห็น)
  • public/runtime-config.js คือ "แผ่นป้ายประกาศจริง" (ที่พนักงานเอาออกมาแขวนไว้ที่เสาหน้าประตู เพื่อให้คนไข้ที่เดินเข้ามาอ่านได้)

2. ตารางเปรียบเทียบหน้าที่และความแตกต่าง

หัวข้อ scripts/write-runtime-config.mjs public/runtime-config.js
มันคืออะไร? โค้ดคำสั่ง / สคริปต์ (Script / Tool) ที่สั่งให้ทำงาน ไฟล์ข้อมูลผลลัพธ์ (Artifact / Static Asset)
ใครเป็นคนสั่งรัน? โปรแกรมเมอร์ หรือ ระบบ Build (Node.js) บนคอมพิวเตอร์ เว็บบราวเซอร์บนมือถือของคนไข้ เป็นคนโหลดไปเปิดอ่าน
คนไข้บนอินเทอร์เน็ตมองเห็นไหม? ❌ มองไม่เห็นเด็ดขาด อยู่ในเครื่องพัฒนาเท่านั้น ✅ มองเห็นได้โดยตรง ผ่าน URL สาธารณะ
หน้าที่ของมัน ไปหยิบค่าจาก .env ตรวจสอบความถูกต้อง แล้วเขียนลงไฟล์ เก็บตัวแปร window.PATIENT_APP_ENV ให้หน้าเว็บ React ใช้งาน

3. ความลับของโฟลเดอร์ public/ ใน Next.js

ใน Next.js โฟลเดอร์ชื่อ public มีความหมายพิเศษตามชื่อของมันคือ "พื้นที่สาธารณะ"

ไฟล์อะไรก็ตามที่คุณวางไว้ในโฟลเดอร์นี้ เซิร์ฟเวอร์จะเปิดให้ทุกคนบนโลกอินเทอร์เน็ตสามารถพิมพ์ URL เข้ามาเปิดดูได้ตรงๆ เช่น รูปภาพโลโก้, ไอคอนเว็บ (favicon.ico), และไฟล์ runtime-config.js

นั่นเป็นเหตุผลที่ไฟล์ [src/app/layout.tsx](file:///c:/Users/Acer/Desktop/Queue-Hostpital/src/app/layout.tsx#L18) สามารถเขียนคำสั่งนี้ได้: 

<Script src="/patient/runtime-config.js" strategy="beforeInteractive" />

เพราะไฟล์อยู่ใน public/ บราวเซอร์จึงดาวน์โหลดมาอ่านได้ตั้งแต่ก่อนที่หน้าจอจะเริ่มแสดงผล!

4. วงจรการทำงานครบวงจร (Life Cycle)

ขั้นที่ 1: สคริปต์เริ่มทำงาน

เมื่อสั่ง build สคริปต์ใน scripts/ จะตื่นขึ้นมาอ่าน .env ตรวจว่า URL ถูกต้องไหม

ขั้นที่ 2: ผลิตไฟล์ออกสู่สาธารณะ

สคริปต์จะนำข้อความ JSON ไปเขียนบันทึกลงใน public/runtime-config.js

ขั้นที่ 3: คนไข้เปิดอ่าน

เมื่อคนไข้เปิดเว็บบนมือถือ บราวเซอร์จะดาวน์โหลดไฟล์จาก public/ ไปเก็บไว้ในหน่วยความจำ (window) ทันที
