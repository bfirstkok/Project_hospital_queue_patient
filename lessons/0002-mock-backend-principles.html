Lesson 0002 • Backend Architecture

ผ่าโครงสร้างและหลักการทำ Mock Backend
ทำความเข้าใจเบื้องลึกของ mock_backend.py ตั้งแต่แนวคิดไปจนถึงท่อส่งข้อมูล

บทก่อนหน้า: 0001: เข้าใจเบื้องหลังและการทำงานของ API

1. ทำไมเราต้องสร้าง Mock Backend ขึ้นมา? (The "Why")

ในการพัฒนาซอฟต์แวร์จริง ปัญหาคลาสสิกที่สุดคือ "ทีมหน้าบ้าน (Frontend) ต้องรอทีมหลังบ้าน (Backend) เขียนเสร็จก่อน ถึงจะเริ่มต่อระบบได้" ทำให้งานล่าช้า

🏥 อุปมา: ห้องซ้อมเสมือนจริงของโรงพยาบาล ก่อนที่ตึกโรงพยาบาลจริงจะสร้างเสร็จ หรือก่อนที่ห้องเก็บเวชระเบียนจริงจะเปิดใช้งาน พยาบาลและเจ้าหน้าที่จำเป็นต้องมี "เคาน์เตอร์จำลองพร้อมหุ่นคนไข้" เพื่อซ้อมกระบวนการทำงาน การแจกบัตรคิว และซ้อมรับมือเหตุฉุกเฉิน

mock_backend.py ทำหน้าที่เป็น "เซิร์ฟเวอร์จำลองเสมือนจริง" ที่ปฏิบัติตามสัญญา (Contract) ทุกข้อ ทำให้หน้าบ้าน (Next.js) พัฒนาและทดสอบการทำงานได้ 100% ทันทีโดยไม่ต้องรอใคร

1. ตัดการพึ่งพาภายนอก (Zero Dependencies)

เขียนด้วย Python Standard Library ล้วนๆ (http.server, json) ไม่ต้องลง pip install อะไรเพิ่ม รันได้บนเครื่องคอมพิวเตอร์ทุกเครื่องทันที

2. ข้อมูลจำลองที่เสถียร (Deterministic Data)

มีข้อมูลคนไข้ทดสอบ เช่น somchai99, บัตรคิว A012 ทำให้รันชุดทดสอบอัตโนมัติ (Playwright E2E) ได้ผลลัพธ์แน่นอน ไม่เปลี่ยนไปมา

3. จำลองเคสวิกฤตได้ง่าย (Edge Case Simulation)

สามารถสั่งให้ส่ง Error แปลกๆ ได้ง่ายดาย เช่น กรอก PIN ผิด 3 ครั้งโดนระงับบัญชี (Status 423), OTP ผิด (400), หรือจำลองเน็ตหลุด

2. เสาหลักทั้ง 5 ของ mock_backend.py

เสาหลักที่ 1: In-Memory Database (ฐานข้อมูลในแรม)

แทนที่จะติดตั้ง PostgreSQL หรือ MongoDB ซึ่งยุ่งยาก เราใช้ Python Dictionary เป็นฐานข้อมูลจำลอง: 

MOCK_PATIENT_PROFILE = {
    "username": "somchai99",
    "hn": "HN-67001",
    "first_name": "สมชาย"
}
MOCK_ACTIVE_QUEUE = { "queue_number": "A012", "status_label": "รอตรวจ" }

ข้อดี: ทำงานเร็วระดับไมโครวินาที และเมื่อต้องการรีเซ็ตข้อมูลทั้งหมดให้กลับมาสะอาดเหมือนใหม่ เพียงแค่กด Ctrl + C แล้วสั่งรันใหม่ ข้อมูลก็กลับสู่ค่าเริ่มต้นทันที

เสาหลักที่ 2: ท่อประปาข้อมูล HTTP (Low-level Stream Mechanics)

เนื่องจากเราไม่ได้ใช้ Framework สำเร็จรูปอย่าง FastAPI หรือ Express.js เราจึงได้เห็น "การทำงานที่แท้จริงของเครือข่ายอินเทอร์เน็ต" ผ่าน 2 ตัวแปรหลัก:

  • self.rfile (Read File Stream): ท่อน้ำท่อรับข้อมูลที่ไหลมาจาก Browser คอมพิวเตอร์ไม่รู้ว่าข้อมูลยาวแค่ไหน เราจึงต้องอ่าน Header Content-Length ก่อน เพื่อรู้ว่าจะต้องดูดน้ำกี่ไบต์ แล้วนำมาแปลงด้วย json.loads()
  • self.wfile (Write File Stream): ท่อน้ำท่อส่งข้อมูลกลับไปยัง Browser เราต้องแปลง Python Dictionary ให้เป็นตัวอักษร JSON แล้วเข้ารหัสเป็นไบต์ encode("utf-8") ก่อนฉีดน้ำลงท่อ

เสาหลักที่ 3: ด่านตรวจคนเข้าเมืองของบราวเซอร์ (CORS Guard)

เมื่อหน้าบ้านรันที่พอร์ต 3000 (Next.js) แต่หลังบ้านรันที่พอร์ต 8000 บราวเซอร์จะมองว่าเป็นคนละคน และสั่ง บล็อกคำขอทิ้งทันที ตามกฎความปลอดภัยสากล (Same-Origin Policy)!

mock_backend.py จึงต้องมี _send_cors_headers() เพื่อออกใบอนุญาต: 

self.send_header("Access-Control-Allow-Origin", "*")
self.send_header("Access-Control-Allow-Methods", "GET, POST, PATCH, OPTIONS")
self.send_header("Access-Control-Allow-Headers", "Content-Type, Authorization")

และต้องมี do_OPTIONS() เพื่อรองรับ Preflight Request ที่บราวเซอร์จะแอบส่งมาเคาะประตูก่อนว่า "ฉันจะส่ง POST มานะ คุณอนุญาตไหม?"

เสาหลักที่ 4: การจัดสรรเคาน์เตอร์บริการ (Routing Dispatcher)

ในคลาส BaseHTTPRequestHandler ของ Python กริยา HTTP จะถูกแมปเข้ากับฟังก์ชันโดยตรง:

  • คำขอแบบ GET จะวิ่งเข้าฟังก์ชัน do_GET(self)
  • คำขอแบบ POST จะวิ่งเข้าฟังก์ชัน do_POST(self)
  • คำขอแบบ PATCH จะวิ่งเข้าฟังก์ชัน do_PATCH(self)

ภายในฟังก์ชัน เราจะใช้เงื่อนไขตรวจสอบ path = self.path.rstrip("/") + "/" เพื่อแยกส่งไปยังเคาน์เตอร์ต่างๆ เช่น /api/patient/login/ หรือ /api/patient/queue/

เสาหลักที่ 5: การส่งสัญญาณสถานะ (Status Code Signaling)

Mock Backend ต้องไม่ส่งแค่ 200 เสมอไป แต่มันจำลองตรรกะจริง เช่น การกด PIN ผิด:

attempts = MOCK_DATABASE_SECURITY["attempts"].get("default", 0) + 1
if attempts >= 3:
    self._send_json(423, {"ok": False, "error": "รหัส PIN ไม่ถูกต้องเกินกำหนด ระบบระงับชั่วคราว"})
else:
    self._send_json(401, {"ok": False, "error": f"รหัส PIN ไม่ถูกต้อง (เหลือโอกาสอีก {3 - attempts} ครั้ง)"})

สิ่งนี้ช่วยให้ฝั่งหน้าบ้านสามารถทดสอบ UI แจ้งเตือนสีแดง และการนับถอยหลังล็อกหน้าจอได้อย่างสมบูรณ์แบบ
