# ผู้เรียนเข้าใจมโนทัศน์การเลือกใช้ HTTP Method และรูปแบบการส่งข้อมูลผ่าน URL ได้อย่างแม่นยำ

ผู้เรียนสามารถวิเคราะห์กรณีการดึงสถานะคิวแบบ Polling ได้อย่างถูกต้องว่าต้องใช้ HTTP Method `GET` และส่งข้อมูลผ่านทาง URL โดยไม่ใช้ Body ซึ่งสะท้อนความเข้าใจในหลักการ Safe/Cacheable และข้อจำกัดของ HTTP Protocol ความเข้าใจรากฐานนี้ทำให้พร้อมต่อการเชื่อมโยงทฤษฎีเข้าสู่โค้ดจริงทั้งฝั่ง Python (`mock_backend.py`) และ Next.js TypeScript (`src/shared/api/patient-api.ts`)
